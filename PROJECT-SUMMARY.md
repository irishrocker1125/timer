## Customization Examples

### Change Warning Colors
Edit CSS in `index.html`:
```css
:root {
    --success: #00d084;      /* Green */
    --warning: #ffd700;      /* Yellow */
    --danger: #ff4757;       /* Red */
}
```

### Adjust Warning Levels
Edit `app.js`:
```javascript
this.settings = {
    warningLevel: 300,       // 5 minutes
    criticalLevel: 60,       // 1 minute
    enableColor: true,
    enableSound: true,
    enableFlash: true,
    enableMilestones: true
}
```

### Add Custom Presets
Edit `app.js`:
```javascript
this.presets = [
    { label: '3m', seconds: 180 },
    { label: '7m', seconds: 420 },
    { label: '20m', seconds: 1200 },
    // Add as many as you want
]
```

## Troubleshooting

### Timer doesn't start
- Ensure `app.js` is loaded (check browser console F12)
- Try pressing Space or clicking START button
- Refresh page (Ctrl+R)

### Display looks wrong
- Clear browser cache (Ctrl+Shift+Delete)
- Hard refresh (Ctrl+Shift+R)
- Try different browser
- Check zoom level (Ctrl+0 to reset)

### Sounds don't work
- Check volume in Windows
- Check browser tab volume
- Verify "Sound Effects" is enabled
- Try different browser

### Fullscreen doesn't work
- Press F key or click ⛶ button
- Some browsers require user action first
- Try starting timer before fullscreen
- Check browser fullscreen permissions
