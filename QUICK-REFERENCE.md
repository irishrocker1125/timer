## QUICK SETUP GUIDE

### For Presentations (15-30 minutes)
```
STEP 1: Select preset (press 3 for 15m or 4 for 30m)
STEP 2: Press F to enter fullscreen
STEP 3: Place timer on stage monitor
STEP 4: Press Space to start when ready
STEP 5: Watch for color changes (Green → Yellow → Red)
STEP 6: Conclude before timer expires
```

### For Workshops (Multiple segments)
```
STEP 1: Set first duration (e.g., press 1 for 5m)
STEP 2: Press Space to start
STEP 3: When finished, press R to reset
STEP 4: Set next duration
STEP 5: Repeat for each activity
```

### For Live Events (Interactive)
```
STEP 1: Choose counter mode (Items / Votes / Tally)
STEP 2: Display on main projector
STEP 3: Use mouse to edit counters
STEP 4: Run event with real-time tracking
```

## COLOR MEANINGS

```
🟢 GREEN   = Plenty of time, no rush
            Presenter has control, flexible

🟡 YELLOW  = Warning level reached (default: 60s)
            Presenter should start wrapping up

🔴 RED     = Critical level reached (default: 10s)
            Immediate action needed, conclude now

⚫ PULSING  = Time expired
            Timer finished, attention needed
```

## TROUBLESHOOTING QUICK FIXES

### Timer won't start
→ **Fix**: Click START button or press SPACE

### Can't see timer from distance
→ **Fix**: Press F for fullscreen, increase monitor size

### Colors look wrong on projector
→ **Fix**: Press L to toggle light/dark theme, adjust brightness

### Sound too loud/quiet
→ **Fix**: Adjust Windows volume, or disable in settings

### Stuck in fullscreen
→ **Fix**: Press ESC key to exit

### Settings not saving
→ **Fix**: Clear browser cache (Ctrl+Shift+Delete), reload

### Timer display incorrect
→ **Fix**: Hard refresh (Ctrl+Shift+R), try different browser

## ADVANCED TIPS

### Pro Tip #1: Dual Monitor Setup
```
Monitor 1 (Laptop):  Normal view with full controls
Monitor 2 (Projector): Fullscreen timer only
→ Control from laptop, display on projector
```

### Pro Tip #2: Custom Warning Times
```
For 60-minute presentations:
• Warning: 10 minutes (600 seconds)
• Critical: 5 minutes (300 seconds)
→ More time to wrap up gracefully
```

### Pro Tip #3: Silent Operation
```
For quiet venues:
• Turn OFF sound effects
• Turn OFF milestone alerts
• Keep ON screen flash
→ Visual alerts only, no disruption
```

### Pro Tip #4: Pre-presentation Test
```
1 minute before:
1. Open index.html
2. Test all keyboard shortcuts
3. Verify colors on your display
4. Check audio levels
5. Practice fullscreen toggle
→ No surprises during presentation
```

### Pro Tip #5: Backup Timing
```
Have phone timer ready as backup
Press START on both simultaneously
→ Safety net if app fails
```
